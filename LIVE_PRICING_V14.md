# Live pricing V14

BuildMyPC now has an automatic live-price refresh path for enabled providers. It never labels a catalog/reference value as live.

## eBay
Create a free eBay Developers Program account, then add `EBAY_CLIENT_ID` and `EBAY_CLIENT_SECRET` to Render environment variables. Browse API access uses an application access token.

## Important
The UI uses the phrase **Best verified offer** rather than “cheapest on the internet”. That is deliberate: no single API guarantees global price coverage.

## Local markets
Market-specific search links are provided where direct live feeds are not enabled.
